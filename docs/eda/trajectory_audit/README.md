# Training trajectory audit

These CSVs were generated by `src.data.trajectory_loader` from the 80 `.track` files under the dataset's `train` folder. Only training tracks were read; raw files live under ignored `data/raw/` and are not included in the repository.

Run again from the repository root:

```powershell
python -m src.data.trajectory_loader "data/raw/train" --output-dir "docs/eda/trajectory_audit"
```

`trajectory_inventory.csv` contains one row per training trip. `trajectory_dataset_summary.csv` contains aggregate counts and medians. The loader preserves observation order and raises an error for malformed rows or non-increasing timestamps.

Audit thresholds:

- Nominal sampling: 1 second; regular if the interval is within 0.25 seconds of 1 second.
- Long gap: interval greater than 1.5 seconds.
- GPS jump: implied haversine speed greater than 50 m/s (180 km/h).
- Stationary interval: implied speed no greater than 0.5 m/s. A stationary cluster is at least 3 consecutive stationary intervals.

Current training-data snapshot: 80 trips and 208,417 observations; median trip has 1,529 observations and lasts 1,710.0 seconds. Median per-trip regular-interval fraction is 99.14%; pooled across all intervals it is 96.51%. The audit flagged 7,273 long gaps, 1,524 GPS-jump intervals, and 6 stationary clusters. These are anomaly flags for review, not automatic row deletion.
